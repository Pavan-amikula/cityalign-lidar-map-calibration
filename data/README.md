# Data acquisition

Run `python -m urban_calibrator.cli download` from the repository root.

Source: https://media.githubusercontent.com/media/PDAL/data/main/autzen/autzen-classified.laz

SHA-256: `c8828215facfb4c9465c9a7db9d45cf2c0e9175a6eb5b21e89417978cc85cd51`

License: [CC BY 4.0](https://github.com/PDAL/data/blob/main/LICENSE). Original data: Watershed Sciences / Aaron Reyna (2010). Manual updated classifications: Hobu / Max Sampson (2021). Distributed by PDAL/data.

Preparation streams 500,000-return LAZ chunks, converts horizontal and vertical axes separately from header CRS units, subtracts the metric source minimum, crops local x=[80,980], y=[650,1410], keeps all building and selected complex-structure returns and every eighth other return. The NPZ cache and full source are ignored by Git. Source metadata is saved alongside every published experiment under `results/`.

Derived Autzen geometry and imagery retain CC BY 4.0 attribution. Synthetic fixture geometry is generated by the MIT-licensed code.
